# Publishing checklist

- Repository public at https://github.com/zamkara/CleanMacaci.
- Root manifest ID `cleaner.zamkara.ati`, page name CleanMacaci.
- Menu label System Cleaner, including custom menu extension metadata.
- README includes install, update, disable, removal, requirements and scope.
- Existing repository license retained; no upstream GPL implementations bundled.
- No home-specific scripts, sibling plugin imports, personal data, reports or credentials committed.
- Run manifest validation and tests before release; complete the graphical lifecycle test on a standard supported Omarchy installation.
- Optional preview must be an intentionally reviewed asset, not an unrelated screenshot.

Suggested category: System. Suggested tags: system, cleanup, maintenance, cache, utilities. No AI feature tag.

Maintainer notes:

> CleanMacaci adds System Cleaner to Omarchy's Setup menu and exposes an optional custom System menu entry. The plugin bundles its Python engine and native Quickshell UI, requires no personal plugins, and preserves unrelated configuration. User cleanup requires explicit confirmation; verified cache layouts are selected automatically, while uncertain data and project artifacts require review. Private profile data, active applications, keep-listed paths and changed preview targets are protected. Privileged system cleanup is separate, interactive and confirmed. Installation, update and removal instructions, dependencies and license are documented in the repository.
